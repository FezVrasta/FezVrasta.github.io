title: 'Why this blog exists'
date: 2026-09-04T09:00:00
dek: "An intro, an admission about AI, and an experiment to see if I can finally keep up with a blog."
---

I want to write about the projects I build: what broke, what I'd do differently, the occasional argument about the platform. I've wanted that for years. What's stopped me every time is the same thing: I don't have time, and writing takes time I don't have.

I've started a handful of blogs because of it. None of them made it past the third post, because the moment writing competes with shipping, writing loses.

So this time I'm doing it differently. I'm using AI to help with the writing itself: I still bring the opinions, the war stories and the technical decisions, it just helps me get them out of my head and onto the page faster than I'd manage alone.

Same goes for a lot of my open source work lately. If a commit message or a PR description reads a bit more polished than it used to, that's why. I still design the systems, review every line and I'm the one who ships it. The tooling just removes the friction between "I know how to fix this" and "this is fixed".

If that bothers you, I get it. But I'm Federico, better known online as Fez Vrasta: fifteen years shipping frontends across security monitoring, machine learning interfaces, medical imaging, betting, Web3, and now AI security. I wrote Popper.js, co-created Floating UI, and spend spare cycles building Home Assistant integrations nobody asked for. I think that counts as a decent enough track record to trust the quality holds up.

So: this is an experiment. Let's see if I can actually keep up with it this time.
